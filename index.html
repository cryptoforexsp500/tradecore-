Kaj je JSONBin.io?
Brezplačen oblačni shranjevalnik za JSON podatke. Deluje kot "mini baza" — ko ti objaviš trejd, se shrani sem, vsi naročniki ga vidijo samodejno brez refresha.

Kako nastaviti (5 minut):
1. Pojdi na jsonbin.io → brezplačna registracija
2. Ustvari 2 BINA (gumb "+ New Bin"):
  – FEED BIN: vsebina {"feed":[],"subscribers":[],"challenge":null} → označi kot PUBLIC
  – SUB BIN: vsebina {"subscribers":[]} → označi kot PUBLIC
3. Pojdi na Account → API Keys → kopiraj X-MASTER-KEY
4. Za vsak bin kopiraj BIN ID (iz URL-ja ali info panela)
5. Prilepi ID-je in ključ spodaj → SAVE & START

✓ Ko nastaviš: naročniki vidijo trejde samodejno vsake 60s, brez refresha.
